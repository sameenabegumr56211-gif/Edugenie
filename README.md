# 📚 EduGenie – Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant designed to help students learn faster and more effectively using Google Gemini AI.

## ✨ Features

- 🤖 Ask a Question – Get AI-powered answers to questions.
- 📖 Explain a Topic – Understand difficult topics in simple language.
- 📝 Generate Quiz – Create quizzes for practice and self-assessment.
- 📄 Summarize Text – Convert lengthy text into concise summaries.
- 🗺️ Create Learning Path – Generate a structured learning plan for a topic.
- 💡 AI-Powered Learning – Uses Google Gemini AI for intelligent responses.
- 💾 Learning History – Stores previous learning activities using Supabase.

## 🎯 Objectives

1. To provide students with an interactive AI learning assistant.

3. To provide personalized learning support.
4. To help students practice through AI-generated quizzes.
5. To create structured learning paths.
6. To summarize educational content quickly and efficiently.
